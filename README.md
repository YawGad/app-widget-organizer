# App & Widget Organizer

React + Vite web app with Capacitor Android packaging.

## Build locally

```bash
npm install
npm run build
npx cap add android   # only needed if the android/ project does not exist
npx cap sync android
cd android
./gradlew assembleDebug
```

The debug APK is generated at `android/app/build/outputs/apk/debug/app-debug.apk`.

## Build with GitHub Actions

The workflow `.github/workflows/build-apk.yml` runs on pushes to `main` and can also be started manually from **GitHub → Actions → Build Android APK → Run workflow**.

When the run succeeds, open the run and download the `app-organizer-debug-apk` artifact. GitHub-hosted workflow artifacts are temporary (14-day retention in this workflow).

## Notes

- This workflow produces a **debug APK** for testing/demo use, not a signed release APK for Play Store publishing.
- The Android project is generated by Capacitor during CI if it is not checked into the repository.
- Do not commit signing keys, passwords, API secrets, or `.env` files.
